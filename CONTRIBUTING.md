# Contributing

This is proprietary, publicly viewable source. Before submitting code, contact the
maintainer through an issue to agree on scope and contribution terms. No implicit
open-source license or transfer of third-party rights is intended.

For bugs, provide reproduction steps, expected/actual behaviour, Aero/macOS versions
and a redacted screenshot when helpful. Use SECURITY.md for vulnerabilities.

For approved changes: use a focused branch, preserve native accessibility and Reduce
Motion behaviour, add meaningful regressions, run the build and both test scripts,
and describe user-visible changes and remaining manual checks in the pull request.
Do not commit accounts, tokens, cookies, browsing databases, logs containing user data,
DerivedData, release artifacts or private signing material.
